# LeetCode 438 - 找到字符串中所有字母异位词 可视化

## 题目描述

给定两个字符串 `s` 和 `p`，找到 `s` 中所有 `p` 的**异位词**的子串，返回这些子串的起始索引。

**异位词**：指由相同字母重排列形成的字符串（包括相同的字符串）。

## 示例

**示例 1:**
- 输入: s = "cbaebabacd", p = "abc"
- 输出: [0, 6]
- 解释:
  - 起始索引 0 的子串是 "cba", 它是 "abc" 的异位词
  - 起始索引 6 的子串是 "bac", 它是 "abc" 的异位词

**示例 2:**
- 输入: s = "abab", p = "ab"
- 输出: [0, 1, 2]

## 算法原理

### 滑动窗口 + 字符计数

1. **初始化窗口**: 窗口大小固定为 p 的长度
2. **字符计数**: 统计窗口内和 p 中每个字符出现的次数
3. **比较**: 判断两个字符计数是否相同
4. **滑动**: 窗口向右移动，更新字符计数
5. **记录**: 发现匹配时记录起始索引

### 时间复杂度
- 时间复杂度: O(n)，n 为字符串 s 的长度
- 空间复杂度: O(1)，字符集大小固定(26个小写字母)
